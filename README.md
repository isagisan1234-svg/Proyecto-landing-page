Mundo Anime 🎌

Mi tercer proyecto de desarrollo web y mi primera vez creando una landing page básica.

Este proyecto forma parte de mi proceso de aprendizaje en desarrollo web. Mi objetivo fue poner en práctica los conocimientos que he adquirido de HTML y CSS, construyendo una página sencilla y organizando sus diferentes secciones.

🛠️ Tecnologías utilizadas

- HTML5: para crear la estructura de la página.
- CSS3: para diseñar y dar estilo a los elementos.
- Flexbox: para organizar los elementos y crear distribuciones en filas.

📚 Lo que aprendí

Durante este proyecto practiqué:

- La creación de un encabezado con enlaces de navegación.
- La organización de imágenes y textos en tarjetas usando Flexbox.
- La creación de una sección de cita.
- El diseño de una sección de contacto con correo electrónico.
- La construcción de un pie de página.
- El uso de Git y GitHub para registrar y guardar los cambios del proyecto.

🎯 Objetivo

El objetivo principal fue practicar los fundamentos de HTML y CSS mediante una landing page sencilla. Aunque todavía estoy aprendiendo, este proyecto representa un paso más en mi camino como desarrollador web.
